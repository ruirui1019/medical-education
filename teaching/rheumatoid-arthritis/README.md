# 类风湿关节炎｜内科学课堂课件

面向临床医学专业本科四年级，按提供的90分钟讲稿制作，共25页。

## 文件

- `rheumatoid-arthritis.pptx`：16:9图片式课件，备注区包含对应原始讲稿；页面文字无法逐项编辑。
- `rheumatoid-arthritis.pdf`：便于阅读与打印的课件。
- `source.md`：用户提供的完整原始教学讲稿。
- `outline.md`：逐页大纲和视觉规范。
- `prompts/`：25页完整图片生成提示词，可据此重新生成单页。

## 结构

病例导入 → 概念与机制 → 临床表现 → 检查与分类评分 → 鉴别诊断 → 评估与治疗 → 病例回顾、总结和思考题。

原讲稿22页主体内容中，2010 ACR/EULAR分类标准拆为两页，另将课堂总结及思考题各列一页，总计25页。病例为教学模拟，图像为生成的医学教学示意，不是真实患者照片或诊断影像。分类标准、抗体解读和用药安全边界均按提供材料保留。

## 来源与制作

主要依据用户提供的《内科学》第10版相关教学讲稿，未进行独立教材逐页核查。采用 [baoyu-slide-deck](https://github.com/jimliu/baoyu-skills/tree/main/skills/baoyu-slide-deck) 工作流，以原生图像生成工具制作各页，再合并为PPTX/PDF。原始讲稿写入演讲者备注。
